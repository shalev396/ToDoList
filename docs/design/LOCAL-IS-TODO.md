# Where "a local item is a to-do" is assumed

Audit for the time blocks, areas and travel plan (spec: `docs/superpowers/specs/2026-11-17-time-blocks-design.md`, "Decisions after review" 1 and 7). Two new local item kinds are coming: `block` (a time block, or a painted area with `props.layer: 'area'`) and `travel` (a travel leg). They are TodoList's own reserved time, not markable to-dos: no status to move, never completed, hidden from task views, never copied to a provider, never pushed to the workspace calendar.

Each row is a place that would treat such an item as a to-do today. Later tasks tick the "Done" column with the commit that fixed it. Line numbers are from the audit commit and will drift. Paths are repo-relative.

Task keys (from the plan): 2 shared recurrence, 3 kinds and class, 4 query shapes, 5 TimeBlock class and Subjects, 6 client create flow, 7 client sheet and edit, 8 time views, 11 travel storage, 12 travel generation, 14 MCP travel, 17 timeline "+".
